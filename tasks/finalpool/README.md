# Final Pool

This branch collects all tasks currently marked **implemented** in the Notion
Task Tracker (`Task Status Table`). Each subdirectory corresponds to one accepted
task and contains its task definition files (`docs/task.md`,
`docs/agent_system_prompt.md`, optional `docs/user_system_prompt.md`),
`evaluation/main.py`, and `groundtruth_workspace/readme.txt`, matching the layout
of `tasks/examples/example-task`.
